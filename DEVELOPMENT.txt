TOWER DEFENSE — DEVELOPMENT STEPS
==================================

COMMANDS
--------
Compile:      ./mvnw compile
Run tests:    ./mvnw test
Launch UI:    ./mvnw javafx:run
Clean build:  ./mvnw clean compile


STEP 1 — Project Scaffold + Core Domain Model           [DONE]
--------------------------------------------------------------
Goal: Runnable Maven + JavaFX skeleton with all core interfaces
and abstract classes defined. Nothing playable yet.

Deliverables:
  - pom.xml (Maven, Java 21, JavaFX 21, JUnit 4)
  - .gitignore
  - mvnw wrapper script
  - Enemy         (interface)  — move(), takeDamage(), isAlive(), getPosition()
  - Tower         (abstract)   — attack(List<Enemy>), holds TargetingStrategy
  - Projectile    (interface)  — update(), hasHit(), getTarget()
  - Cell                       — row/col + type (EMPTY, PATH, TOWER)
  - GameMap                    — grid, fixed U-shaped enemy path
  - GameState                  — lives, score, wave, gold (plain data, no logic)
  - TargetingStrategy (interface) — declared here, implemented in Step 2
  - TowerDefenseApp            — blank JavaFX window entry point

Done when: ./mvnw javafx:run launches a blank window with no errors.


STEP 2 — Strategy + Factory Method (Game Logic, No UI)
------------------------------------------------------
Goal: Towers shoot enemies, enemies walk the path.
Fully testable without a UI.

Patterns introduced:
  - Strategy      — tower targeting behavior
  - Factory Method — wave enemy spawning

Deliverables:
  Strategies (com.towerdefense.pattern.strategy):
    - NearestEnemyStrategy
    - StrongestEnemyStrategy
    - FirstInPathStrategy

  Concrete towers (com.towerdefense.model.tower):
    - BasicTower   — balanced stats,     NearestEnemyStrategy
    - SniperTower  — long range/damage,  StrongestEnemyStrategy
    - SplashTower  — area damage,        FirstInPathStrategy

  Enemy factories (com.towerdefense.pattern.factory):
    - EnemyFactory (abstract)
    - BasicEnemyFactory
    - FastEnemyFactory
    - ArmoredEnemyFactory
    - WaveSpawner  — picks factories per wave number

  Concrete enemies (com.towerdefense.model.enemy):
    - BasicEnemy
    - FastEnemy
    - ArmoredEnemy

  - GameEngine    — tick loop: move enemies → towers fire → check deaths

Done when: a JUnit test drives GameEngine through 3 waves and
enemies die without any UI.


STEP 3 — Observer + Command (State, Events, Undo)
-------------------------------------------------
Goal: Game state changes propagate automatically;
tower actions are undoable.

Patterns introduced:
  - Observer — game state notifies listeners
  - Command  — tower actions with undo

Deliverables:
  Observer (com.towerdefense.pattern.observer):
    - GameObserver (interface) — onLivesChanged(), onScoreChanged(), onWaveChanged()
    - GameState becomes the subject — addObserver(), notifyObservers()

  Commands (com.towerdefense.pattern.command):
    - GameCommand (interface) — execute(), undo()
    - PlaceTowerCommand
    - SellTowerCommand
    - UpgradeTowerCommand
    - CommandHistory — stack-based undo

Done when: commands execute/undo correctly in JUnit; GameState
notifies mock observers on every state change.


STEP 4 — JavaFX UI + JSON Persistence
--------------------------------------
Goal: Fully playable game with a visual grid, live HUD,
and save/load.

Deliverables:
  UI (com.towerdefense.ui):
    - MapGridView        — renders GameMap as tiles, clicks dispatch PlaceTowerCommand
    - HudView            — displays lives/score/wave, implements GameObserver
    - TowerSelectionPanel — choose tower type before placing
    - Undo button        — calls CommandHistory.undo()

  Persistence (com.towerdefense.persistence):
    - GameSaveService    — serializes CommandHistory to JSON
    - GameLoadService    — replays JSON commands to reconstruct state
    - Save/Load buttons in UI

  App wiring (TowerDefenseApp):
    - Manual dependency injection — no framework
    - Injects strategies into towers, observers into GameState,
      CommandHistory into controller

Done when: full playthrough works — place towers, waves spawn,
enemies walk, lives/score update live, save + reload restores state.
